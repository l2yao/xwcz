# 熏聞成種法教維基（LLM Wiki）

本維基以「LLM Wiki」模式維護，整理 **成德法師（熏聞成種 / xwcz.org）** 的傳統中文佛學開示。原始資料在 `doc/`（僅能由同步工具更動），本目錄 `wiki/` 是由 LLM 持續編寫、互相連結的知識庫。

## 三層架構

1. **原始資料** `doc/影音/` — 由 `packages/api-client` 從 xwcz 公開 API 同步的逐集文稿（12+ 類別、257 相簿、1,833 集），不可手動更動。
2. **維基** `wiki/` — LLM 撰寫的頁面：類別、主題、開示（每相簿一頁）、概念、問答。
3. **綱要** `AGENTS.md` + `wiki/SCHEMA.md` — 規範結構與工作流程。

## 使用方式

- 瀏覽：用 Obsidian 開啟本資料夾，看圖論（graph view）與雙向連結。
- 問問題：告訴 LLM 你的問題，它會查索引、合成答案並附出處。
- 回饋：若某頁過時或矛盾，讓 LLM 執行 lint 檢查。
